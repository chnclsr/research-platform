# Research Platform v0.4.0 — İlk Uygulama Raporu

Belge sürümü: `1.0`  
Platform sürümü: `v0.4.0-dev`  
Tarih: `2026-07-16`

## Sonuç

Research Platform'ın Codex, Claude ve Telegram tarafından ortak araştırma servisi olarak
kullanılmasını sağlayan ilk dikey dilim uygulandı.

## Uygulanan parçalar

- `raw`, `result` ve `both` teslimat sözleşmesi
- Ham source-version JSONL artifact'i
- Normalize passage JSONL artifact'i
- Ham, sonuç ve birleşik ZIP paketleri
- Teslimat indirme API endpoint'i
- Ortak async Research Gateway API istemcisi
- Yedi araç sunan MCP server
- MCP Streamable HTTP bearer ve Origin koruması
- Telegram long-polling botu
- Telegram kullanıcı ve chat allowlist'i
- Docker Compose MCP ve opsiyonel Telegram servisleri
- Codex ve Claude örnek MCP yapılandırmaları

## Açık işler

1. Telegram run aboneliklerini PostgreSQL'de kalıcı tutmak.
2. Run tamamlanınca istenen paketi Telegram'a otomatik göndermek.
3. Ofis ağı için onaylı VPN/reverse proxy ve TLS kurmak.
4. Kullanıcı bazlı API anahtarı, kota ve audit trail eklemek.
5. Uzak bir Codex ve Claude istemcisinden gerçek araştırma kabul testi yapmak.
6. Büyük ham veri için claim/query-branch bazlı context pack üretmek.
7. Windows tek komutlu kurulum ve servis başlangıcını v0.4 bileşenleriyle güncellemek.

## Sürüm kararı

Bu nokta `v0.4.0-dev` geliştirme checkpoint'idir. Uzak Codex/Claude kabul testi, Telegram otomatik
teslim ve ofis ağı güvenlik testi tamamlanmadan `v0.4.0` final etiketi oluşturulmamalıdır.
